# Pulse

An emotional insight engine. Capture how you feel, then find the correlations between states, context, and what actually moves your day.

## Concept

- Capture with minimal friction
- Correlation analysis across captured states
- Insight generation
- Mood tracking over time

## Targets

- iOS
- PulseMac
- PulseWatch

## Stack

- SwiftUI
- SwiftData
- XcodeGen (`project.yml`)

## Structure

Key types: `AnalysisService`, `CorrelationService`, `CaptureView`/`CaptureViewModel`, `ContentView`, `AppStoreListingView`.

Version 1.0.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.

Xcode projects here were generated with XcodeGen (`project.yml`); open the `.xcodeproj` directly.
